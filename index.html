🏡 A good home

I put some work into getting these datasets ready, but I don’t have time to tend to the care and feeding of all of them. I’m sure I’ve made mistakes, and they’re hard for me to catch because I’m not a user of most of these datasets. I’m looking for someone who wants to claim each one: maintain it, give it regular attention, keep it open and available to the community, and reach out to the researchers and others who might use it.

  • All of these run automatically and pull data from a government website. Most have no API that the government hosts, and many involve PDFs or web scraping. On Hugging Face you can query all of them in one place, and the websites let anyone filter and find what they need.
  • Each one comes with a GitHub repo for the code, a Hugging Face repo for the data and a basic website. I’m hosting the websites for now, but I’d like to stop.
  • To take one over, you need an engineer or someone engineer-like. Someone who will respond when something breaks, check on it now and then, and fix the code when something is off.
  • Some need an LLM API key, because I pull fields out of unstructured text. I use Claude. The bills are small (see each card). There’s no other spend.
  • I wrote a handoff document for each one to help your engineer take over. You’ll need to sign up for a few free accounts.

Federal J&A Documents

Why federal contracts skipped competition.

  • Refreshes daily
  • Live sites
  • LLM key
Size
20,019 notices and 22,160 attachments (about 11 GB)
LLM cost
About $4.50 a month

What you get

  • Every justification notice on SAM.gov since January 2025, with the original files and text
  • An LLM pulls out the vendor, dollar value, legal reason and a summary (experimental)
  • A daily email digest of the notable ones

Code: Apache 2.0 · Data: CC0
